ИНСТРУКЦИЯ ПО ЗАПУСКУ AR-СТРЕЛЬЦА

1. ЗАГРУЗКА НА GITHUB PAGES
   - Загрузи ВСЮ папку целиком в свой репозиторий arzamas-ar-1:
     - index.html (в корень репозитория)
     - assets/streltsy.png (папка assets внутри репозитория)
     - assets/marker_hiro.png (это картинка маркера для печати)
   - Подожди 1-2 минуты, пока GitHub Pages обновится

2. ПЕЧАТЬ МАРКЕРА
   - Распечатай файл marker_hiro.png на белом листе A4
   - Это стандартный тестовый маркер "Hiro" - его использует библиотека AR.js
   - Повесь на стену/стенд в музее

3. ТЕСТИРОВАНИЕ
   - Открой на телефоне https://aihm152.github.io/arzamas-ar-1/
   - Разреши доступ к камере
   - Наведи камеру на распечатанный маркер
   - Стрелец появится прямо на маркере и будет плавно покачиваться
   - Отойди дальше - фигура уменьшится
   - Подойди ближе - увеличится
   - Это и есть привязка размера к расстоянию через маркер!

4. ЧТО ДАЛЬШЕ
   - Когда протестируем что все работает - заменим тестовый маркер Hiro
     на кастомный маркер с символикой Арзамаса
   - Добавим анимацию текста, золотые искры и парящую подпись
   - Сделаем второй маркер для крепости
