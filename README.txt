ИНСТРУКЦИЯ ПО ЗАПУСКУ AR-СТРЕЛЬЦА (ФИНАЛЬНАЯ ВЕРСИЯ С QR-КОДОМ)

СТРУКТУРА ФАЙЛОВ (загружать именно так, по отдельности, НЕ архивом):
- index.html               -> в КОРЕНЬ репозитория
- assets/streltsy.png      -> в папку assets
- assets/marker_hiro.png   -> в папку assets (это маркер для печати)
- qr_code_streltsy.png     -> просто для тебя, распечатать/показать посетителям

============================================
ШАГ 1. ПРОВЕРКА GITHUB PAGES
============================================
1. Открой репозиторий -> Settings -> Pages
2. Source: "Deploy from a branch"
3. Branch: main, папка "/ (root)"
4. Save
5. Подожди 1-2 минуты, скопируй ссылку которая появится сверху
   (обычно вида https://твой-логин.github.io/название-репо/)

============================================
ШАГ 2. ЗАГРУЗКА ФАЙЛОВ
============================================
1. Удали старые ZIP-архивы из репозитория (если есть) - GitHub Pages
   не умеет их распаковывать сам
2. Загрузи index.html в корень
3. Загрузи assets/streltsy.png и assets/marker_hiro.png -
   при загрузке впиши путь "assets/имя_файла.png", GitHub сам создаст папку
4. Commit changes

============================================
ШАГ 3. QR-КОД - ГЛАВНАЯ ФИШКА
============================================
QR-код в файле qr_code_streltsy.png уже зашифровывает прямую ссылку
на твою AR-страницу. Посетителю не нужно ничего вводить руками:

1. Распечатай qr_code_streltsy.png (например на стенде рядом с маркером)
2. Посетитель открывает камеру телефона / любое приложение для QR
3. Наводит на код -> телефон сам предлагает открыть ссылку
4. Открывается страница -> разрешает камеру -> наводит на маркер Hiro
5. Стрелец появляется и покачивается

ВАЖНО: если ты поменяешь ссылку GitHub Pages (например переименуешь
репозиторий), QR-код перестанет работать - нужно будет сгенерировать новый.
Сейчас код зашит на ссылку:
https://aihm152.github.io/arzamas-ar-1/

============================================
ШАГ 4. РАСПЕЧАТКА
============================================
Распечатай ДВА листа А4:
1. marker_hiro.png - на этот маркер "садится" стрелец
2. qr_code_streltsy.png - его сканируют чтобы открыть страницу

Можно расположить рядом на одном стенде: QR сверху с подписью
"Отсканируй меня", маркер снизу с подписью "Наведи камеру сюда".
