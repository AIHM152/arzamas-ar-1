ИНСТРУКЦИЯ ПО ЗАПУСКУ AR-СТРЕЛЬЦА (ФИНАЛЬНАЯ ВЕРСИЯ v4)
============================================================

СТРУКТУРА ФАЙЛОВ (загружать по отдельности, НЕ архивом целиком):
- index.html               -> в КОРЕНЬ репозитория
- assets/streltsy.png      -> в папку assets (картинка с прозрачным фоном)
- assets/marker_hiro.png   -> в папку assets (маркер для печати)
- qr_code_streltsy.png     -> просто для тебя, распечатать/показать посетителям

============================================================
ЧТО ИСПРАВЛЕНО В ЭТОЙ ВЕРСИИ
============================================================
1. Прозрачность фона у стрельца - убран белый фон, настоящий альфа-канал
2. Явная настройка transparent/alphaTest в material - фон больше не рисуется
   белым прямоугольником в AR.js
3. Усиленная анимация - теперь 3 слоя движения одновременно:
   - Покачивание вверх-вниз (20 см амплитуда)
   - Лёгкий наклон влево-вправо (6 градусов)
   - Пульсация масштаба (+-3%)
4. Cache-busting (?v=3 в пути к картинке) - чтобы браузер не показывал
   старую закэшированную версию файла

============================================================
ШАГ 1. ПРОВЕРКА GITHUB PAGES
============================================================
1. Открой репозиторий -> Settings -> Pages
2. Source: "Deploy from a branch"
3. Branch: main, папка "/ (root)"
4. Save, подожди 1-2 минуты

============================================================
ШАГ 2. ЗАГРУЗКА ФАЙЛОВ
============================================================
1. Удали старые ZIP-архивы из репозитория, если остались - GitHub Pages
   не распаковывает архивы сам
2. Загрузи index.html в корень (замени старый, если спросит - подтверди)
3. Загрузи assets/streltsy.png и assets/marker_hiro.png - при загрузке
   впиши путь "assets/имя_файла.png" в поле имени, GitHub создаст папку сам
4. Commit changes

============================================================
ШАГ 3. QR-КОД
============================================================
QR-код зашифровывает ссылку: https://aihm152.github.io/arzamas-ar-1/
Посетителю не нужно вводить ссылку руками - просто сканирует камерой
телефона и переходит на страницу автоматически.

Если название репозитория изменится - нужно сгенерировать новый QR-код.

============================================================
ШАГ 4. ПРОВЕРКА НА ТЕЛЕФОНЕ
============================================================
После загрузки файлов ОБЯЗАТЕЛЬНО:
1. Полностью очисти кэш браузера на телефоне ИЛИ открой ссылку
   в режиме инкогнито (это критично - иначе увидишь старую версию)
2. Разреши доступ к камере
3. Наведи на распечатанный marker_hiro.png
4. Стрелец появится на прозрачном фоне и будет покачиваться,
   наклоняться и слегка пульсировать

============================================================
РАСПЕЧАТКА ДЛЯ СТЕНДА
============================================================
Распечатай два листа А4:
1. marker_hiro.png - на него "садится" фигура стрельца
2. qr_code_streltsy.png - его сканируют чтобы открыть AR-страницу

Расположить можно рядом: QR сверху с подписью "Отсканируй меня",
маркер снизу с подписью "Наведи камеру сюда".
